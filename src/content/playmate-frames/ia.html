Information architecture

Five tabs. Create sits in the middle of the tab bar, one tap from anywhere.

Open the app→4 intro screens→Sign up, log in or guest
The tab bar: five places to go
Home
  • Upcoming matches
  • Game details and participants
  • Join or add to calendar
  • Games to rate
Discover
  • Map or list of games
  • Filter by sport, skill and time
  • Preview of the closest match
  • Pick a game
+Create
  • Choose a sport
  • Set the location
  • Date, time and player limits
  • Set a skill filter
  • Create the game
Friends
  • Friends and recent chats
  • Friend list
  • Post-game feedback
Profile
  • About: skill level and sports
  • Reliability rating
  • Reviews from players
  • No-show log
  • Settings
